If this existing Flux environment still has an older scikit-learn, upgrade the
active environment without `--no-deps` so Narwhals is installed too:

python -m pip install --upgrade "scikit-learn==1.9.0" "narwhals>=2.0.1"

An installation previously done with `--no-deps` can be repaired with:

python -m pip install "narwhals>=2.0.1"

These commands change the activated `/p/hym/conda_envs/nova-perlmutter`
environment persistently. Confirm the Python path before installing, then
check the environment:

which python
python -m pip check
python -c "import sys, numpy, sklearn, narwhals, torch; print(sys.executable); print('numpy', numpy.__version__); print('sklearn', sklearn.__version__); print('narwhals', narwhals.__version__); print('torch', torch.__version__); print('cuda available:', torch.cuda.is_available())"
